# E-Commerce Conversion Funnel & Behavioral Analysis Dashboard

## 📌 Project Overview

This project features an interactive data analytics dashboard built to analyze and optimize the e-commerce customer journey. Utilizing a dataset of 10,000 user sessions, the dashboard tracks user progression from initial product browsing to the final checkout and purchase stages.

The goal of this project is to identify drop-off points in the sales funnel, analyze user behavior across different device categories and regions, and evaluate marketing channel performance to drive higher conversion rates and revenue.
