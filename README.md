# E-Commerce Conversion Funnel & Behavioral Analysis Dashboard

## 📌 Project Overview

This project features an interactive data analytics dashboard built to analyze and optimize the e-commerce customer journey. Utilizing a dataset of 10,000 user sessions, the dashboard tracks user progression from initial product browsing to the final checkout and purchase stages.

The goal of this project is to identify drop-off points in the sales funnel, analyze user behavior across different device categories and regions, and evaluate marketing channel performance to drive higher conversion rates and revenue.

## 📊 Key Features & Insights
The dashboard is split into core operational views to provide comprehensive insights:

Conversion Funnel Tracking: Visually maps user progression across key milestones (Browse ➔ Add to Cart ➔ Checkout ➔ Purchase) to pinpoint where the largest customer drop-offs occur.

Behavioral Segmentation: Analyzes performance metrics based on user demographics and setup, including Device Type (Desktop, Mobile, Tablet) and Geographic Region.

Acquisition Channel Analysis: Evaluates which marketing channels (Organic, Google Ads, Social Media, Email) yield the highest quality traffic, conversion rates, and revenue.

Bounce Rate & Engagement Monitoring: Tracks friction points by correlating bounce flags against specific product categories and session parameters.
## 💾 About the Dataset
The analysis is driven by funnel_analysis_data.csv, which contains simulated e-commerce session logs. Key attributes include:

* User_ID & Session_ID: Unique identifiers for tracking users and individual visits.

* Event: Customer actions (Browse, Add to Cart, Checkout, Purchase).

* Timestamp: Precise date and time of the event for chronological journey mapping.

* Device: The hardware used (Mobile, Desktop, Tablet).

* Region: Geographic location of the session.

* Channel: The marketing source that brought the user to the site.

* Product_Category: The specific department browsed (e.g., Electronics, Fashion, Beauty, Sports, Home).

* Revenue: Financial value generated by completed purchase events.

* Bounce_Flag: Indicates whether a user left the site immediately after viewing only one page.
